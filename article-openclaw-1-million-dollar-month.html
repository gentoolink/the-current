$1.3 Million a Month to Run 100 AI Coders — What the OpenClaw Bill Actually Means

Peter Steinberger posted his OpenAI API invoice online. The numbers are real. Here's what they tell us about the actual cost structure of autonomous coding agents at scale.

Data · May 18, 2026 · 7 min read

On a Friday afternoon, Peter Steinberger — Austrian developer, OpenClaw creator, and now OpenAI employee — posted a screenshot to social media. It showed $1,305,088.81 in OpenAI API charges over 30 days. That was the number that made people react. But the more interesting number is 603 billion.

That's how many tokens Steinberger's fleet of roughly 100 AI coding agents consumed in that same period, processing 7.6 million API requests in service of building OpenClaw — the open-source autonomous coding agent that has amassed over 300,000 GitHub stars since launching in late 2025. Three people. One hundred agents. No significant human intervention in the coding process.

The numbers in context

603 billion tokens in a month is an extraordinary figure. For comparison: a typical LLM-powered coding session might consume a few hundred thousand tokens. Steinberger's operation processed that many tokens per hour. The bill reflects Codex's "Fast Mode" pricing, which OpenAI says operates at a significantly higher credit consumption rate than standard execution. Disable Fast Mode and the monthly cost drops to roughly $300,000 — still enormous, but a 77% reduction that makes the economics at least discussable.

Individual agent tasks give a sense of the operational scale. Steinberger described agents that open pull requests based on the project roadmap, monitor performance benchmarks and flag regressions to Discord, review pull requests, scan commits for security vulnerabilities, and — most futuristically — listen in on team meetings and generate PRs for features that were discussed. A three-person team overseeing what amounts to a continuous, autonomous development operation.

Why the $1.3M figure matters beyond the headline

Every discussion of this story defaults to "that's insane" or "that's just rich-person research." Both reactions miss what the data actually shows.

First, the billing transparency. OpenAI shifted Codex to token-based pricing in April 2026. What Steinberger did — posting the invoice publicly — is now straightforwardly possible for any developer using these tools. The cost structure that was previously opaque is now visible. That changes how teams plan agentic tooling: you can actually model whether the productivity gain from an autonomous coding agent exceeds its API cost. Before April, you couldn't easily do that math.

Second, the Fast Mode signal. The $300,000 baseline versus the $1.3M actual reveals that the premium for faster agent response times is roughly $1M per month in this configuration. That's a real number — but it's also a dial. Teams that don't need sub-second agent responses can cut their bill dramatically. The question isn't whether agentic coding is expensive; it's whether the speed premium is worth it for your use case.

Third, the enterprise interest. Nvidia is developing "Nemoclaw," an open-source enterprise-focused competitor to OpenClaw. That a chip company with no obvious developer tooling business is building a coding agent competitor tells you something about where they think the compute demand is heading. If the compute cost is $1.3M/month for three developers, the chip demand at scale is substantial.

The honest catch

Steinberger frames the spending as "research into what software development looks like if token costs weren't a constraint." That's an honest framing for a personal project — but it also obscures that the results are only possible because he has the financial runway to sustain $1.3M/month while the model finds its price point. Most teams can't run this experiment. Most investors won't fund it. The insight is real; the applicability is limited.

The other catch is more structural. These agents are productive when the problem is well-defined, the codebase is clean, and the testing is automated. Steinberger is working on an open-source project with good existing infrastructure. The same agents dropped into a messy legacy codebase with poor test coverage would generate a very different cost-per-useful-output ratio. Agentic coding is not universally cost-effective — it's cost-effective in specific conditions that most real-world development teams don't have.

The Cursor database deletion incident from earlier this year is the other side of this coin. When agents have broad system access and the cost of a wrong action is low, the risk calculation is different from when every action costs real money. The $1.3M/month figure is impressive; what it doesn't show is the failure modes that haven't generated viral screenshots yet.

What this means for teams watching the space

If you're evaluating autonomous coding agents for your team, the OpenClaw data point is useful in one specific way: it gives you a real upper bound on what high-intensity agentic development costs at current API pricing. Three developers with 100 agents spent $1.3M in a month. You can reverse-engineer your own cost envelope from that number — what headcount does that replace, what throughput does that generate, and is the math favorable against your alternatives?

The answer will differ by team and by use case. But the era of having to guess at the economics is over. The invoice was posted. The numbers are on the table.
